## Miks need failid

- `repo-kokkuvote-ja-esitlusbrief.md`
  - Koondab projekti loo, git ajaloo põhised faasid, õppetunnid ja praeguse seisu.
- `vahekaitsmine-slaidid.md`
  - Annab 10 minuti esitlusnarratiivi.
- `projekti_kirjeldus.md`
  - Lühiülevaade töö eesmärgist ja panusest.
- `microwakeword-sanity-check.md`
  - Selgitab, kuidas treeningu- ja evaluatsioonitoru valideeriti.
- `2026-02-12-esp32-s3-korvo2-voice-satellite.md`
  - Kirjeldab esimest päris riistvarakatset ja sealt saadud õppetunde.
- `taltech-slaidipohi-notebooklm-10slides.pdf`
  - TalTechi slaidimalli stiilireferents umbes 10 erineva slaiditüübiga.
