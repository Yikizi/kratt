This bachelor's thesis investigates how to build and evaluate an Estonian wake-word detector for a resource-constrained smart-home microcontroller. The work focuses on the \enquote{Kratt} project, whose target is local detection of the phrase \enquote{Kuule Kratt} on an ESP32-S3 class device without relying on cloud services. The practical motivation is that Estonian speech-to-text already has viable local solutions, whereas wake-word detection remains the missing front-end component that determines the usability of the whole voice pipeline.

The thesis reconstructs and fixes a \texttt{microWakeWord}-based training and evaluation pipeline, validates it with a public sanity-check experiment on the \texttt{Speech Commands} dataset, and then applies the corrected pipeline to a sequence of Estonian wake-word model versions. The main methodological finding is that the initial clip-level evaluation produced overly optimistic results because of data leakage in the negative test setup. To correct this, truly held-out evaluation sets were created, explicit train--test disjointness checks were added, and streaming evaluation with FAPH (false activations per hour) was adopted as the primary false-trigger metric.

The corrected results show that no single metric is sufficient for model selection. Different model versions optimized different aspects of performance, including unseen-speaker recall, hard-negative discrimination, and low false-activation rates. As a practical extension, the work also evaluates a consensus approach with specialized expert models. This reduced false activations to 0.8 FAPH on held-out Estonian Common Voice speech, at the cost of lower recall.

The main contribution of the thesis is to show that, in a low-resource Estonian wake-word setting, the central challenge is not only model training but also methodologically sound evaluation. The outcome is a reproducible pipeline, a documented data and evaluation protocol, and an empirical mapping of the trade-offs between recall, hard-negative rejection, and false activations for the Estonian wake phrase \enquote{Kuule Kratt}.
