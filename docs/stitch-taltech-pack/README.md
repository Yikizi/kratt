# TalTech Stitch Pack

See kaust on kokku pandud failidest, mida on kõige mõistlikum Google Stitchi üles laadida, et saada TalTechi slaidimalli põhjal kasutatavad visuaalsed assetid ja stiilisuund.

## Soovitatud upload-järjekord Stitchi

1. `taltech_brand_board.png`
2. `taltech_logo_dark.png` või `taltech_logo_light.png`
3. `taltech_palette.png`
4. `taltech_courtyard_hero.jpg`
5. `taltech_brand_gradient.jpg`

## Failide otstarve

- `taltech_brand_board.png`
  - Parim üksik fail, kui tahad Stitchile anda korraga kogu visuaalse suuna.
- `taltech_logo_dark.png`
  - Valge logo tumedal taustal. Hea, kui Stitch kasutab tumedaid kaarte või hero-sektsioone.
- `taltech_logo_light.png`
  - Helehall logo heledale taustale.
- `taltech_palette.png`
  - TalTechi põhivärvid pildina.
- `taltech_courtyard_hero.jpg`
  - TalTechi kampuse foto, sobib hero- või taustapildiks.
- `taltech_city_hero.jpg`
  - Mallis kasutatud lisafoto, sobib sektsioonivahe või inspiratsioonipildina.
- `taltech_brand_gradient.jpg`
  - Malli iseloomulik roosa-sinine gradient.

## Referentsfailid

- `taltech_title_reference.png`
- `taltech_section_reference.png`
- `taltech_footer_reference.png`

Need on kasulikud stiilireferentsina, aga mitte nii puhtad kui eraldi välja võetud core assetid. Need pärinevad süsteemi preview-renderist ja neis võib mõni originaal-PowerPointi detail olla mittetäielik.

## Praktiline soovitus

Kui tahad kõige stabiilsemat tulemust, lae Stitchi esmalt üles:

- `taltech_brand_board.png`
- `taltech_logo_dark.png`
- `taltech_palette.png`

ja lisa prompti mõte stiilis:

`Design a web or mobile UI in TalTech brand style using bold magenta accents, deep navy typography, soft gray surfaces, the supplied TalTech logo, and the supplied gradient/photo assets.`
