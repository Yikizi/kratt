This file captures concrete formatting/content rules that can be missed by high-level best-practice validation.

## High-confidence rules from the 2025 IT faculty guide

### Document volume

- Bachelor thesis main body is generally **25–35 pages**.
- Master thesis main body is generally **30–60 pages**.
- Main body includes **introduction, thesis chapters, and summary/conclusion**.
- The thesis should be “as large as necessary and as small as possible”; deviations are allowed if justified and accepted by supervisor.

### Abstract / lühikokkuvõte length

Important correction: the explicit **½ A4 page** rule applies to the **lühikokkuvõte in the thesis main language**, not to the introduction.

- Abstract/summary in thesis main language: **½ A4 page**.
- Abstract/summary in the other language: **at least 1 A4 page**.
- If the second-language abstract is not in the thesis main language, the translated thesis title is added before it.
- Estonian abstract final required wording:
  - `Lõputöö on kirjutatud [keel] keeles ning sisaldab teksti [lehekülgede arv töö põhiosas] leheküljel, [peatükkide arv] peatükki, [jooniste arv] joonist, [tabelite arv] tabelit.`
- English abstract final required wording:
  - `The thesis is in [language] and contains [pages] pages of text, [chapters] chapters, [figures] figures, [tables] tables.`

### Introduction content

No exact introduction page-count rule was found in the 2025 guide text extracted by `pdftotext`.

The introduction must give an overview of:

- thesis topic, including relevance and novelty;
- thesis goal;
- researched problem;
- hypotheses, research questions, or questions to be solved;
- thesis structure;
- starting conditions;
- subtasks;
- additional requirements if needed.

### Main chapters / body logic

The guide describes core body functions:

- Background / literature review: relevant theories, concepts, previous research, problem context.
- Methodology: methods, data collection, tools, and work stages.
- Results and analysis: how data were analysed, main results, conclusions and patterns.
- Results must be tied back to problems stated in the introduction.
- Synthesis / author solution: combine analysed data into a whole and offer author-side solutions; for practical work, include applied recommendations.
- Future work is optional and used where relevant.

### Summary / conclusion content

The summary/conclusion must include:

- main goal(s);
- answers to questions raised in the introduction;
- most important results;
- conclusions.

### Required and optional parts

Required:

- title page;
- author declaration;
- abstract/lühikokkuvõte in thesis main language;
- abstract/lühikokkuvõte in English/Estonian depending on main language;
- table of contents;
- introduction;
- thesis chapters;
- summary/conclusion;
- bibliography / references;
- licence / lihtlitsents.

Optional / if needed:

- abbreviations and glossary;
- list of figures;
- list of tables;
- appendices.

### Page and heading rules

- Page numbering is continuous from title page to final appendix.
- Title page counts as page 1 but does not show the page number.
- Page number appears at bottom centre, 1.5 cm from lower edge, Times New Roman 12 pt.
- Independent parts such as TOC and introduction start on a new page.
- Use at most three heading levels; avoid fourth-level headings.
- Do not create subsections with only one paragraph.
- A new subheading, figure, or table must not immediately follow a heading; there must be text after a heading.
- Headings start with capital letter, generally no hyphenation or abbreviations, and no final full stop.

### Figures and tables

- All figures and tables must be numbered throughout.
- Every figure/table must be referenced in the main text before the figure/table appears.
- Tables have a title; figures have a caption/signature.
- Caption/title ends with a full stop.
- Caption/title must be on the same page as the figure/table.
- Caption/title is centred, Times New Roman 10 pt, spacing 6 pt before/after.
- Table contents use Times New Roman 11 pt, line spacing 1.0.
- Avoid tables spanning multiple pages; if unavoidable, repeat the table header on every page.

### Code and formulas

- Program code should be unbroken on one page where possible and properly indented.
- Program code is captioned as a figure.
- Referenced formulas should be numbered; if a formula is part of a sentence, the sentence still ends with a full stop.

### Licence and appendices

- The licence / lihtlitsents must be included in the same PDF as the electronic thesis.
- It is appendix 1 / Lisa 1.
- It is a prerequisite for being allowed to defend.
- It does not need to be signed.
- Appendices are optional, numbered and clearly titled.
- Every appendix must be referred to in the main text.
