# Trademark and branding policy

This project uses the names **Kratt** and **Kuule Kratt** for the Estonian wake-word and Home Assistant voice prototype.

The source code and project-owned model artifacts are licensed under Apache-2.0 unless otherwise noted. That license does **not** grant permission to use Kratt names, logos, or other branding in a way that suggests endorsement, official status, or origin from the Kratt maintainer.

## Allowed uses

You may use the Kratt name to:

- refer accurately to this project;
- describe compatibility, for example "works with Kratt";
- keep attribution notices required by the license;
- identify unmodified copies or forks that clearly link back to the original project.

## Uses that need permission

Please ask before using Kratt branding to:

- publish an app, add-on repository, device, or commercial service as "Kratt" or "official Kratt";
- use Kratt names/logos as the primary brand for a modified fork;
- imply endorsement, certification, partnership, or official support;
- register domain names, package names, app-store listings, or social accounts that could be confused with the official project.

## Fork naming

Modified forks should use a clearly distinct name and state that they are based on Kratt. For example:

> ExampleVoice, based on the Kratt open-source project.

Do not call a modified fork simply "Kratt" unless you have explicit permission.

## No registered trademark claim

This file is a project branding policy. It does not assert that the marks are registered trademarks. It records the maintainer's intent to keep the project identity distinct while keeping the code and model artifacts open source.

For permission requests, contact the maintainer through the public repository issue tracker or profile contact information.
