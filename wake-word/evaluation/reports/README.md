# Evaluation reports

Optional home for curated wake-word evaluation reports that should live next to the evaluation code.

For thesis-facing evidence, prefer `docs/research/artifacts/<dated-run>/` so the evidence is easy to find from the thesis/research documentation. Use this directory when a report is primarily useful to developers running `wake-word/evaluation` tooling.

Keep ad-hoc generated files out of git; flat files produced directly under `wake-word/evaluation/` are ignored by default. Promote only selected, documented outputs into this directory or `docs/research/artifacts/`.
